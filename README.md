# @hydrooj/presentation

Hydro OJ 比赛演示插件，提供比赛的实时排行榜、倒计时、评测队列和首杀（FTS）展示，适用于比赛现场大屏投影。

## 功能

- **实时排行榜**：显示当前队伍排名、解题数、罚时及各题状态
- **倒计时页面**：比赛开始前/进行中/结束后自动切换倒计时画面
- **评测队列**：实时展示正在评测和最近的提交记录
- **首杀（FTS）**：每个题目的首个 AC 队伍展示
- **封榜支持**：封榜后隐藏评测结果，仅显示提交状态

## 安装

```bash
# 全局安装（将 /root/xxx 替换为克隆后的文件夹绝对路径）
yarn global add /root/xxx

# 注册为 Hydro OJ 插件
hydrooj addon add /root/xxx
```

## 使用

安装完成后，访问比赛即可使用演示页面：

- **演示页**：`/d/{domainId}/contest/{tid}/presentation`
- **状态接口**：`/d/{domainId}/contest/{tid}/presentation/state`

将演示页全屏投屏到比赛现场大屏即可实时展示比赛动态。

## 页面说明

| 页面 | 用途 |
|------|------|
| 排行榜 | 展示队伍排名、解题数、罚时及每题 AC/WA 状态 |
| 评测队列 | 展示当前正在评测和最近的提交流水 |
| 倒计时 | 比赛开始前/结束时自动全屏倒计时 |
| 首杀 | 展示每道题的首个通过队伍 |
